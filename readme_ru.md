# Audex

[![MIT license](https://img.shields.io/badge/license-MIT-blue.svg)](./LICENSE)

Расширение для [Flarum](https://flarum.org), которое управляет **скрипт-блоками** и вставляет их в страницы форума **на стороне сервера** — полностью пропуская их для исключённых пользователей и участников выбранных групп. Реклама, аналитика, виджеты — любой HTML/JS.

## Возможности

- Несколько скрипт-блоков (любой HTML/JS: рекламные сети, аналитика, виджеты и т.д.).
- Размещение per-block: внутри `<head>`, перед закрывающим `</body>` или в **зоне виджетов** через опциональную интеграцию с [fof/forum-widgets-core](https://github.com/FriendsOfFlarum/forum-widgets-core).
- Включение/выключение каждого блока, изменение порядка.
- **Исключения**: перечисленные пользователи и участники выбранных групп вообще не получают скрипты — код отсутствует в их HTML, ничего не загружается и не выполняется в браузере.
- Гости всегда видят рекламу (так задумано).
- Валидация настроек при сохранении (структура JSON, размеры, безопасные имена).

## Установка

```bash
composer require stezkoy/flarum-audex
```

## Использование

1. Включите расширение.
2. Откройте его страницу настроек в админке.
3. Добавьте блок: вставьте сниппет в том виде, как его дал источник (включая теги script), выберите размещение, включите блок.
4. Настройте исключения: выберите группы и/или конкретных пользователей.
5. Удалите код, который раньше вставляли вручную — теперь это делает Audex.

Правило простое:

- **Полный сниппет** (со своими тегами `<script>`) → вставляется как есть.
- **Чистый JavaScript** (без тега script) → автоматически оборачивается в `<script>`.

> **Примечание:** внутри JS-строк пишите `</script>` как `<\/script>`, иначе браузер посчитает тег закрытым раньше времени (это стандартное поведение HTML-парсера, а не ограничение расширения).

## Как работают исключения

Flarum рендерит страницы в PHP, поэтому Audex знает текущего пользователя **до** отправки HTML. Для исключённого пользователя скрипты просто не добавляются в документ — никаких CSS-прятанья, клиентских трюков и запросов к рекламной сети.
