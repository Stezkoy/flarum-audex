# Audex

[![MIT license](https://img.shields.io/badge/license-MIT-blue.svg)](./LICENSE)

Расширение для [Flarum](https://flarum.org), которое управляет **скрипт-блоками** и вставляет их в страницы форума **на стороне сервера** — полностью пропуская их для исключённых пользователей и участников выбранных групп. Реклама, аналитика, виджеты — любой HTML/JS.

## Возможности

- **Скрипт-блоки** — управление множеством блоков: имя, включение/выключение, порядок.
- **Размещение на каждый блок:**
  - `head` — внутри `<head>` страницы;
  - `body` — перед закрывающим `</body>`;
  - `widget` — показывается внутри виджета [fof/forum-widgets-core](https://github.com/FriendsOfFlarum/forum-widgets-core); зона настраивается в редакторе виджетов fof (опциональная интеграция).
- **Исключения** — перечисленные пользователи и участники выбранных групп вообще не получают скрипты: код отсутствует в их HTML, в payload страницы, а эндпоинт виджета отдаёт им пустой ответ. Ничего не загружается и не выполняется в браузере.
- **Гости не исключаются** (так задумано) — всегда получают скрипты.
- **Умные сниппеты** — полный сниппет (со своими тегами `<script>`) вставляется как есть; чистый JavaScript без тега script автоматически оборачивается в него.
- **Статус виджета** — при выключенном forum-widgets-core блоки `widget` помечаются в админке как «widget — выкл».
- **Валидация** — структура JSON, число блоков, безопасность имён и лимиты размеров проверяются при сохранении.

## Установка

```bash
composer require stezkoy/flarum-audex
php flarum cache:clear
```

Опционально: для размещения «widget» установите [fof/forum-widgets-core](https://github.com/FriendsOfFlarum/forum-widgets-core) (`composer require fof/forum-widgets-core`). Без него Audex работает только с head/body.

## Использование

1. Включите расширение.
2. Откройте его страницу настроек в админке.
3. Добавьте блок: вставьте сниппет в том виде, как его дал источник (включая теги script), выберите размещение, включите блок.
4. Для размещения `widget`: откройте **fof → Редактор виджетов** и перетащите виджет Audex в нужную зону.
5. Настройте исключения: выберите группы и/или конкретных пользователей.
6. Удалите код, который раньше вставляли вручную — теперь это делает Audex.

Зоны виджетов отображаются только на главной странице форума — это ограничение секций fof, а не Audex.

> **Примечание:** внутри JS-строк пишите `</script>` как `<\/script>`, иначе браузер посчитает тег закрытым раньше времени (это стандартное поведение HTML-парсера, а не ограничение расширения).

## Как работают исключения

Flarum рендерит страницы в PHP, поэтому Audex знает текущего пользователя **до** отправки HTML. Для исключённого пользователя скрипты просто не добавляются в документ — никаких CSS-прятанья, клиентских трюков и запросов к рекламной сети. То же правило на стороне сервера проверяет эндпоинт контента виджета, а флаг в payload страницы вообще не даёт виджету смонтироваться у исключённых.
